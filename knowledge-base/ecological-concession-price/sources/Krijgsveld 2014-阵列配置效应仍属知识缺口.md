# Krijgsveld (2014)

## 一句话结论

政府委托综述指出，常用碰撞风险模型通常不纳入风机间距、相对海岸朝向和风场规模，因为配置如何影响避让仍不清楚；同时认为在规划期结合主要飞行路径调整配置可能降低碰撞与屏障效应。

## 对本研究的意义

这不是“平行朝向有效”的证据，而是该研究问题确实存在且尚未解决的直接证据。最合适的引用位置是研究缺口，而不是结果或机制段。
