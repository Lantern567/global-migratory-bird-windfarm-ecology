# BALTRAD / Aloft：欧洲天气雷达生物目标数据

## 数据内容

BALTRAD VPTS 是从欧洲业务天气雷达提取的生物目标垂直廓线时间序列，包含目标密度、速度、方向、时间和高度层。Aloft 提供浏览与下载入口。

## 优点

- 方向、强度和高度同时存在；
- 时间分辨率高，适合春秋和昼夜分层；
- 无需先制作高分辨率物种密度图即可计算场址周边主方向。

## 限制

- 雷达通常不能可靠识别物种；
- 海上与雷达边缘覆盖不足；
- 生物目标可能混入昆虫，需要质量控制和季节/速度过滤。

外部链接：[Aloft](https://aloftdata.eu/)、[Zenodo VPTS](https://zenodo.org/records/13683295)、[Scientific Data 数据论文](https://www.nature.com/articles/s41597-025-04641-5)。
